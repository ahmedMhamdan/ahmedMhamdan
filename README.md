## Featured projects

### [Elancer](https://github.com/ahmedMhamdan/Elancer)

A bilingual freelance marketplace, covering project posting, proposals, hiring, contracts,
private messaging, deliveries, and reviews. Built with Laravel, Inertia, React, and TypeScript, with authorization,
automated tests, and Stripe/Moyasar payments in test mode.
[Live demo](https://elancer.onrender.com).

### [Jawla / جولة](https://jawla-h6nk.onrender.com)

A bilingual Arabic/English trivia game for two teams, built for friends and family. Each game brings six categories
and 36 questions, with team helpers and host-controlled scoring.
[Play Jawla](https://jawla-h6nk.onrender.com).

### [ResolveIQ AI Helpdesk](https://github.com/ahmedMhamdan/resolveiq-ai-helpdesk)

A Laravel helpdesk with role-based workflows, authentication, a REST API, rate limiting, AI ticket assistance through
LLM APIs (OpenRouter and OpenAI), Arabic/English support, and automated feature tests.
[Live demo](https://resolveiq-ai-helpdesk.onrender.com).
